# Discord Debloat

A Discord theme that hides annoying UI clutter. Written for Vencord, but works with other client mods.

## Hidden elements
* **Chat bar:** Gift, Stickers and Apps buttons
* **Sidebars:** Nitro, Shop, Quests and Discover tabs
* **Profile popout:** Badges and Orbs rows
* **Top bar:** Help (`?`) button

## Installation
**1. Online theme (Auto-Updates)**

Paste this link into **User Settings > Vencord > Themes > Online Themes**:
```text
https://raw.githubusercontent.com/f4lenn/discord-debloat/main/DiscordDebloat.theme.css
```

**2. Local theme**

Download [`DiscordDebloat.theme.css`](https://raw.githubusercontent.com/f4lenn/discord-debloat/main/DiscordDebloat.theme.css), place it in your `themes` folder and turn the theme on in settings.

**3. QuickCSS**

Paste this line into your QuickCSS file:
```css
@import url("https://raw.githubusercontent.com/f4lenn/discord-debloat/main/DiscordDebloat.theme.css");
```
